# Бот поиска фильмов по коду

Telegram-бот на Python (aiogram 3, SQLite). Пользователь отправляет числовой код — бот присылает название фильма и описание (если задано). Языки интерфейса: русский и узбекский (латиница).

## Что умеет бот

Для зрителя:

- `/start` — приветствие и выбор языка (по умолчанию русский).
- Отправить код (только цифры) — получить название фильма, а также год, жанр и описание, если они заданы. Если у фильма есть постер, он придёт фотографией с этой подписью. Видео бот не отправляет.
- Если кода нет — понятное сообщение.
- `/top` — топ-10 фильмов по просмотрам.
- `/lang` — сменить язык, `/help` — справка.

Если включена обязательная подписка и добавлены каналы, перед выдачей фильма бот проверяет подписку. Пользователь видит кнопки каналов и «Проверить подписку».

Для администратора:

- `/add` — добавить фильм: название, затем по желанию год/жанр/описание и постер (фото, можно пропустить), затем свободный или свой код.
- `/add Интерстеллар` — то же, название уже указано, код назначится сам.
- `/add 12 Интерстеллар` — сразу название и код 12 (если код свободен, после доп. полей фильм сохранится).
- `/add 12` — сначала название, код 12 предпочтителен.
- `/del 42` — удалить фильм (с подтверждением).
- `/edit 42` — изменить название, год, жанр, описание, код или постер.
- `/list` — постраничный список фильмов.
- `/stats` — пользователи, фильмы, поиски и просмотры.
- `/broadcast` — прислать сообщение и после подтверждения разослать его всем пользователям.
- `/channels` — список каналов обязательной подписки, добавление (`@username` или числовой ID), удаление, включение и выключение проверки.
- `/admin` — панель администратора (кнопки: фильмы, статистика, каналы, админы, рассылка). Кнопка панели также появляется в `/help`.
- `/admins` — список администраторов.
- `/addadmin` — добавить администратора (только главный админ из `ADMIN_IDS`): укажите ID или `@username` (человек уже должен был нажать /start), либо ответьте / перешлите его сообщение. Подтверждение кнопками. Новый админ получает уведомление.
- `/deladmin` — снять права (только главный админ). Главных администраторов из `.env` удалить нельзя.
- `/cancel` — отменить текущий шаг.

ID в `ADMIN_IDS` — это главные (владельцы) бота: они не удаляются командами и только они могут добавлять и снимать администраторов. Остальные админы хранятся в базе `data/bot.db` (таблица `admins`). Проверка прав всегда смотрит и `.env`, и базу. Обновление кода безопасно для уже существующей базы: новая таблица создаётся автоматически, фильмы и пользователи не затираются.

Удалённые коды снова выдаются как «следующий свободный».

Для проверки обязательной подписки бот должен быть администратором каждого указанного канала.

## Подготовка: токен и свой ID

1. В Telegram откройте [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, задайте имя и username бота (должен оканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456789:AAE...`. Скопируйте его — это `BOT_TOKEN`. Никому не показывайте токен.
4. Откройте [@userinfobot](https://t.me/userinfobot) и нажмите Start — бот покажет ваш числовой **Id**. Это `ADMIN_IDS` — главные администраторы (их нельзя снять командой `/deladmin`). Если главных несколько, перечислите ID через запятую: `111,222`. Дополнительных админов потом можно назначить из бота: `/addadmin`.

## Запуск на Windows

1. Установите [Python 3.11+](https://www.python.org/downloads/), на шаге установки отметьте **Add python.exe to PATH**.
2. Скопируйте файл `.env.example` в `.env` (в этой же папке).
3. Откройте `.env` блокнотом и подставьте токен и свой ID:

```
BOT_TOKEN=вставьте_токен_от_BotFather
ADMIN_IDS=вставьте_свой_id
```

4. Дважды нажмите `run.bat`. Скрипт создаст виртуальное окружение, установит зависимости и запустит бота.
5. Напишите боту в Telegram `/start`. Остановка — Ctrl+C в окне или закрытие окна.

Пока компьютер выключен, бот в Telegram не отвечает. Чтобы он работал постоянно, его можно позже перенести на Linux-сервер (см. ниже).

Запуск вручную (если не хотите `run.bat`):

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python -m bot
```

База данных создаётся автоматически в `data/bot.db`. Файл `.env` в архив и в git не входит — храните его только у себя.

## Запуск на Linux / в Docker

На сервере с Docker:

```
cp .env.example .env
# отредактируйте .env
docker compose up -d --build
```

База будет в папке `data/` рядом с `docker-compose.yml`. Логи: `docker compose logs -f`. Остановка: `docker compose down`.

Без Docker:

```
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python -m bot
```

Для автозапуска удобно оформить systemd-сервис или оставить Docker с `restart: unless-stopped`.

## Структура проекта

```
bot/            — код бота
  db.py         — база SQLite
  texts.py      — тексты на русском и узбекском
  handlers/     — команды пользователей и админов
data/           — база (создаётся при запуске)
tests/          — автономные тесты (без Telegram)
.env.example    — образец настроек
run.bat         — запуск на Windows
Dockerfile, docker-compose.yml
```

## Тесты

```
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Тесты не обращаются к Telegram и не требуют токена.
